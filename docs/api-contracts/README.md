- `auth-service.yaml` - Authentication service API
- `profile-service.yaml` - Profile service API
- `appointment-service.yaml` - Appointment service API
- `consultation-service.yaml` - Consultation service API
- `video-chat-service.yaml` - Video & Chat service API
- `payment-insurance-service.yaml` - Payment service API
- `medical-records-service.yaml` - Medical records service API
- `notification-service.yaml` - Notification service API
- `hospital-admin-service.yaml` - Hospital admin service API
- `super-admin-service.yaml` - Super admin service API
- `audit-compliance-service.yaml` - Audit service API

## Gateway API

- `api-gateway.yaml` - Complete API Gateway specification

## Usage

These OpenAPI specs can be used to:
- Generate API clients
- Generate server stubs
- API documentation (Swagger UI)
- Contract testing
